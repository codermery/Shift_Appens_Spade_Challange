Autonomous Drone Navigation and Landing Using Lidar-Based SLAM and Path Planning

In this project, we aim to develop an autonomous drone system capable of performing real-time 3D-like mapping, localization, and safe landing using a sensor such as a 2D Lidar with angular scanning capabilities.

The drone is expected to take off from a starting point and navigate through a semi-structured course that may contain various types of obstacles, such as walls, nets, chairs, and pole-like columns wrapped in bubble wrap.Environmental perception will be based on sensor data from devices like Lidar, which will be used to build a basic map and estimate the drone's approximate position.

The goal is for the drone to detect a region between two walls and initiate an automatic landing procedure when it identifies that it is approximately one meter away from the back wall.

Classical path planning algorithms such as A* or Dijkstra are planned to be used to calculate safe navigation routes.This way, the drone can reach the desired landing zone by avoiding obstacles in real time.

The project aims to build a SLAM-like system and achieve basic autonomous navigation in GPS-denied environments.
